# Пользовательский интерфейс и интеграции через user.js

Необязательный `user.js` рядом с `index.html` позволяет добавить уведомление,
ссылки, кнопки или подключение выбранного автором сервиса. Изменять код движка
для этого не требуется. Отдельный CSS-файл не нужен: стили можно создать из JS.

## Начало работы

1. Скопируйте корневой `user-example.js` в `user.js` рядом с `index.html`.
   После установки update-архива пример доступен в `docs/examples/user-example.js`.
2. Откройте проект. Появится учебное уведомление с кнопками выбора.
3. Настройте текст и поведение в `user.js`, затем обновите страницу.

Сам `user-example.js` никогда не подключается автоматически. Если `user.js`
отсутствует, новелла работает без расширения и без уведомления. При попытке
загрузки отсутствующего файла браузер может показать 404 или ошибку `file://`
в консоли; это не ошибка запуска движка.

`user.js` не включается в официальные архивы. Для локальной работы с исходниками
движка добавьте `/user.js` в `.git/info/exclude`, чтобы не включить свой
неотслеживаемый файл в коммит. Эта настройка действует только в вашей копии
репозитория. При публикации собственной новеллы добавьте свой файл самостоятельно.
Update-архив не заменяет `user.js` и корневой `user-example.js`; актуальный
учебный пример поставляется в `docs/examples/user-example.js`.

## Контракт запуска

Обычный скрипт выполняется браузером автоматически. Рекомендуемый контракт
авторского файла — объект `window.VN_USER` с функцией `init(api)`:

```javascript
window.VN_USER = {
  // Добавляет авторскую ссылку после подготовки интерфейса движка.
  init: function(api) {
    var link = document.createElement("a");
    link.textContent = "О проекте";
    link.href = "README.md";
    link.style.cssText = "position:absolute;top:16px;right:16px;pointer-events:auto;";
    api.root.appendChild(link);
  }
};
```

Движок запрашивает `user.js` после выполнения обязательных runtime-скриптов
и автоматически вызывает `init` один раз за загрузку страницы. DOM интерфейса
уже подготовлен; завершение проверки лицензии, отрисовка первой сцены и загрузка
медиа этим контрактом не гарантируются. Перезапуск истории не вызывает `init`
повторно; F5 создаёт новый экземпляр страницы и расширения.

| Поле `api` | Значение |
| --- | --- |
| `version` | Версия этого интерфейса: `1` |
| `root` | Контейнер `#vn-user-root` для авторских элементов |
| `projectId` | Значение `[meta] projectId` либо пустая строка |
| `isLocal` | `true` при открытии через `file://` |

Объект `api` заморожен; его DOM-контейнер можно наполнять. Внутреннее состояние
исполнителя не является частью API. События переходов между сценами и выборов
пока не предоставляются.

Ожидание загрузки `user.js` и возвращённого из `init` Promise не задерживает
запуск истории. Ошибка вызова `init`, включая отклонённый Promise, выводится
как предупреждение `[User]`, а контейнер расширения удаляется. Изменения вне
контейнера, таймеры и уже подключённые сервисы автоматически не откатываются.
Синтаксические ошибки и исключения верхнего уровня также видны в консоли браузера.

## Авторский интерфейс и оформление

Контейнер расположен вне сцены, поэтому клики по его элементам не попадают
в обработчики перелистывания и жестов сцены. Его пустая область пропускает
нажатия; у интерактивных элементов нужно включить `pointer-events: auto`.
Создаваемый из JS элемент `<style>` удобно помещать внутрь `api.root`.
Ограничивайте селекторы префиксом `#vn-user-root` и собственными классами.
Общие правила для `button`, `body` или `*` могут изменить оформление новеллы.

Проверьте уведомление на небольшом экране, с клавиатуры, при открытых настройках,
мини-играх и других накладывающихся элементах. Расширение самостоятельно отвечает
за расположение, доступные подписи, фокус и порядок своих элементов.

## Что демонстрирует пример

`ExampleAnalytics` — вымышленное название. В примере нет реального счётчика,
внешних адресов, загрузки стороннего кода или отправки данных. Функции
`connectAnalytics` и `disconnectAnalytics` только выводят сообщения в консоль.
При `file://` даже заглушка подключения не запускается, но уведомление работает.

Пример показывает явный выбор, сохранение ответа, его пересмотр и синхронизацию
между открытыми вкладками одного проекта. Без ответа и после отказа заглушка
подключения не вызывается. После сохранённого разрешения она вызывается при
следующем открытии страницы через HTTP(S). Отзыв вызывает заглушку отключения.

Выбор хранится в `localStorage`, отдельно от автосохранения истории, с префиксом
`vn:user:example-analytics:`. Ключ включает `projectId` или путь страницы и
`settings.choiceVersion`. Изменение версии запрашивает новый выбор. Запрет
хранилища не ломает пример, но ответ не переживает обновление страницы.
Параметр движка `nosave` управляет автосохранением истории и не отключает
хранилище авторского расширения. Cookies этот пример не создаёт.

В начале файла доступны настройки текста, версии выбора и `policyUrl`.
Пустой `policyUrl` не создаёт ссылку. Укажите адрес собственного подготовленного
документа перед публикацией реального уведомления.

**Это учебный пример интерфейса, а не готовое решение для соблюдения
законодательства и не юридическая рекомендация.** Автор самостоятельно проверяет
применимые требования, документы, тексты и порядок получения, хранения и отзыва
согласия. Для реальной интеграции изучите актуальную официальную документацию
выбранного сервиса. Сохранённый флаг не доказывает корректность всего процесса.

Реальный внешний скрипт подключайте только в подходящей точке обработки выбора.
Отдельно реализуйте отключение сервиса: смена значения в `localStorage` сама
по себе не останавливает уже работающий счётчик. Проверьте сетевые запросы до
выбора, после отказа, при повторном посещении и после отзыва, включая другие
вкладки. Недоступность сервиса не должна мешать прохождению новеллы.

## Граница доверия

`user.js` — доверенный исполняемый код с правами основной страницы, в том числе
доступом к DOM, хранилищу и сети. Он не изолируется Worker-режимом сценариев или
sandbox мини-игр. Подключённые им сторонние скрипты получают те же полномочия.
Обработчик ошибок не защищает от бесконечного цикла или намеренного изменения
движка. Подключайте только проверенный авторский код; учитывайте CSP сайта при
добавлении внешних сервисов, не ослабляя ограничения без необходимости.
